Requerimientos Funcionales

 Estos puntos describen las acciones específicas que el sistema debe realizar para cumplir con su propósito pedagógico y administrativo: 

− RF1: El sistema debe permitir el registro y autenticación de tutores legales mediante correo electrónico y contraseña cifrada. 

− RF2: El sistema debe permitir que un tutor registre a uno o más niños, asociando datos como nombre, edad y necesidades de atención específicas. 

− RF3: El sistema debe mostrar una lista dinámica de talleres interactivos disponibles, detallando su descripción, precio y objetivo pedagógico. 

− RF4: El sistema debe validar la disponibilidad de espacios antes de confirmar una reserva para evitar la sobreventa en el aula inmersiva.  
   
− RF5: El sistema debe procesar la imagen de una webcam en tiempo real para detectar la silueta del usuario utilizando algoritmos de visión artificial. 

− RF6: El sistema debe transformar el movimiento detectado en respuestas visuales y auditivas inmediatas dentro del entorno de aprendizaje.

− RF7: El sistema debe generar un folio de orden único por cada sesión agendada, registrando el monto total y el estado del pago. 

− RF8: El sistema debe almacenar un registro de las sesiones a las que ha asistido cada niño para que el tutor pueda dar seguimiento a su participación.
