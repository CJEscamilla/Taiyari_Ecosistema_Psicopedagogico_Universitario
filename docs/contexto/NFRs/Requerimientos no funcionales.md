Requerimientos No Funcionales

 Estos puntos definen las características de calidad y las restricciones técnicas del entorno:

 − RNF1: El sistema debe funcionar de manera fluida en computadoras portátiles estándar con cámaras web HD, eliminando la necesidad de sensores especializados de alto costo. 

− RNF2: El sistema debe garantizar un tiempo de respuesta inmediato entre el movimiento físico del niño y la reacción visual en pantalla para mantener la inmersión. 

− RNF3: El sistema debe diseñarse para reducir los costos operativos en un 70% en comparación con soluciones que utilizan hardware propietario. 

− RNF4: El sistema debe proteger la información personal y las notas psicopedagógicas de los menores bajo estándares de cifrado de base de datos. 

− RNF5: El sistema debe poseer una interfaz de usuario intuitiva que facilite la navegación a personas con distintos niveles de alfabetización digital. 

− RNF6: El sistema debe ser implementable como un "Kit de Aula Inmersiva" sin requerir modificaciones estructurales en los salones de las escuelas públicas.
