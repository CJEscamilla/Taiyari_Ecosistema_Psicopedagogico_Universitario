# Experiencia de Usuario (UX) - A-TENCION

En esta sección se encuentra documentado el proceso de diseño centrado en el usuario para la plataforma **A-TENCION**. El objetivo principal es garantizar una interfaz intuitiva, accesible y eficiente para padres y terapeutas.

## 📂 Contenido de esta carpeta

Dentro de esta carpeta de evidencias encontrarás los siguientes materiales de diseño:

1. **User Flows / Flujos de Usuario:** Diagramas que muestran el recorrido del padre/terapeuta desde el registro hasta la confirmación de la reserva.
2. **Wireframes (Baja/Alta Fidelidad):** Estructura visual de las pantallas principales (Home, Calendario de Reservas, Panel de Pago).
3. **Guía de Estilos:** Definición de la paleta de colores, tipografías y componentes utilizados para mantener la coherencia visual.
4. **Capturas de Pantalla (Screenshots):** Vistas rápidas de las interfaces finales diseñadas.

## 🎯 Objetivos de UX
* **Accesibilidad:** Diseño pensado para ser fácil de leer y navegar.
* **Claridad en el Agendado:** Reducir la fricción al momento de elegir fechas y realizar pagos.
* **Confianza:** Interfaz profesional que brinde seguridad al usuario al ingresar datos financieros.
