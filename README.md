# Taiyari_Ecosistema_Psicopedagogico_Universitario
Taiyari es una plataforma web integral diseñada para transformar el acompañamiento psicopedagógico en el entorno universitario. El sistema centraliza la gestión de agendas, el monitoreo emocional del estudiante mediante IA y la comunicación remota, facilitando un puente directo y humano entre los alumnos y el departamento de psicología.

📅 Agendamiento Inteligente: Gestión de citas entre estudiantes y psicólogos con recordatorios automáticos.

📖 Bitácora Emocional: Diario personal donde los estudiantes registran sus pensamientos y estados de ánimo.

🤖 Análisis con IA: Implementación de APIs de Procesamiento de Lenguaje Natural (NLP) para detectar patrones de ansiedad o depresión en los registros del diario.

🎥 Teleconsulta Integrada: Módulo de videollamadas (vía Jitsi, Daily.co o Twilio) para sesiones de terapia sin salir de la plataforma.

📊 Dashboard Psicopedagógico: Panel de control para que el profesional visualice el progreso y alertas de sus pacientes.
